# GourmetOn

Landing page para apresentação do aplicativo de delivery GourmetOn. O projeto foi desenvolvido para o Check-Point 05 de Web Development with JavaScript.

## Tecnologias

- React
- Vite
- Tailwind CSS
- Font Awesome
- Fetch API
- Spoonacular API

## Como executar

```bash
npm install
npm run dev
```
